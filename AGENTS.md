# Project guidance

- Read `CONVERSION_PLAN.md` before implementation; the target is the supplied
  Crowther–Woods 350-point version.
- Read `HANDOFF.md` for the last verified milestone, deployment, and next steps.
- Preserve `original/` as reference material. Put the modern implementation and
  generated artifacts elsewhere; document any legacy fixes in the port.
- Keep game rules independent of text and graphics presentation. Both interfaces
  must share state transitions, scoring, and turn timing.
- Keep the README's project status and run instructions accurate as playable
  milestones are added.
